# React + Tailwind SPA Template

A lightweight starter template for building new Single-Page Applications in this repository.

## How to use this template

1. Copy this folder and rename it:
   ```bash
   cp -r apps/_template-react-tailwind apps/my-new-app
   ```
2. Open `apps/my-new-app/index.html` and customize:
   - Change the `<title>` and favicon emoji.
   - Replace the React `<App />` component with your app logic and Tailwind styles.
   - Ensure all assets (images, audio, JSON) use relative URLs (`./`).
3. Register your new app in the root `index.html` `APPS` array so it appears on the main launcher gallery.
4. That's it! No build command or dependencies required.
