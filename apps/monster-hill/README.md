# Monster Hill! — Kids Truck Adventure

A chunky, kid-friendly physics hill-climb game inspired by **Drive Mad** and **Hill Climb Racing**, designed for ages **4–5**.

- **Controls**: Giant on-screen `◀ BRAKE` and `GAS ▶` pedals, or Left/Right Arrow keys / `A` & `D`.
- **Kid-Friendly Auto-Flip Roll Cage**: Flipping upside down bounces the truck safely back onto its wheels.
- **9 Stages across 3 Worlds** (*Sunny Meadow*, *Sandy Dunes*, *Moon Craters*) and **4 Unlockable Monster Trucks**.
