# Chomp Hole! — Toy Town Swallower

A joyful, kid-friendly growth arcade game inspired by **Hole.io**, designed for ages **4–5**.

- **Controls**: Drag anywhere on screen or use Arrow / `WASD` keys to glide the smiling Chomp Hole.
- **3 Maps**: *Toy Town*, *Candy Park*, and *Dino Island*.
- **Zen Mode (Default)** for stress-free gobbling, plus **60s Party Timer Mode** and customizable glowing ring colors.
