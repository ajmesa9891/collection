# Metro Dash! — 3D Kids Endless Runner

A bright, kid-friendly 3D three-lane endless runner inspired by **Subway Surfers**, built with Three.js for ages **4–5** (with a **Big Kid Mode** toggle).

- **Controls**: Swipe left/right/up, tap the big on-screen `◀`, `⬆ JUMP`, `▶` buttons, or use Arrow keys / `WASD` + `Space`.
- **Kid Mode (default)**: 3 forgiving hearts, gentle speed, Rainbow Jetpack & Coin Magnet power-ups, and 4 unlockable 3D runners (*Dash Kid*, *Robo Pup*, *Dino Skater*, *Super Cat*).
