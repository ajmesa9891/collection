# green-light-red-light-game
Simple green light, red light game to play with kids.

## Prompt 1

Create a single-file HTML web app for a 'Red Light, Green Light' game. The app should start with a tap-to-play screen that has extra-large emojis 🏃‍♂️🦖. When the user taps, the game should begin, alternating randomly between a full-screen red background and a full-screen green background. The screen should stay on each color for a random duration between 1 and 3 seconds. If the user taps the screen while it's green, they win. If they tap while it's red, they lose. After a win or loss, the screen should display an extra-large result emoji (👍 for win, 👎 for lose). The results screen should include an extra-large emoji button, 🏃‍♂️, to play again that resets the game.

## Prompt 2

Create a single-file HTML web app for a **“Red Light, Green Light”** game with these requirements:

1. **Start Screen**

   * Displays extra-large emojis 🏃‍♂️🦖.
   * A title that says “Tap anywhere to play.”
   * A small Start button is present, but tapping anywhere on the start screen also begins the game.

2. **Game Mechanics**

   * When the game starts, the background alternates randomly between full-screen **red** and **green**.
   * Each color lasts a random duration between **1 and 3 seconds**.
   * If the user taps while the background is green → they **win**.
   * If the user taps while the background is red → they **lose**.

3. **Results Screen**

   * Displays a giant emoji: **👍** for win, **👎** for lose.
   * Shows a giant **🏃‍♂️** emoji below it, styled just like 👍 and 👎 (no button, no background).
   * Tapping anywhere on the results screen (including the 🏃‍♂️ emoji) restarts the game.

4. **Implementation Details**

   * The app should reset cleanly after each round.
   * All visuals should be extra-large and mobile-friendly.
   * Include inline HTML, CSS, and JavaScript in one file.

## Prompt 3

Build a single-file HTML app (inline HTML/CSS/JS) for a “Red Light, Green Light” game: start screen with extra-large 🏃‍♂️🦖 and text “Tap anywhere to play” (include a small Start button but tapping anywhere also starts); when the game begins, the fullscreen background randomly switches between red and green at intervals of 1–3 seconds; tapping while green = win, while red = lose; after a round, show a results screen with a huge 👍 for win or 👎 for lose and a large 🏃‍♂️ emoji below styled like the other emojis (no button or background); tapping anywhere on the results screen (including the 🏃‍♂️) restarts the game; ensure clean reset each round, mobile-friendly sizing, prevent double‑tap zoom, and support Enter/Space keys on desktop.
